# koboyo アイコン探し（日本語）

## 概要

koboyo は手描き一筆書きの SVG アイコンライブラリ。人物・場面・マスコットが厚く、グリッド系アイコンセットとは用途が違う。このスキルは日本語話者の依頼と koboyo の英語検索の間を埋め、**候補を目で見て選んでから配置する**手順を固定する。

MCP ツールは 7 本 ─ `search_icons` / `find_icons_for` / `list_categories` / `list_icons` / `get_icon` / `get_icon_svg` / `get_library_info`。

## 手順

### 1. 依頼から概念を割り出す

依頼文を、アイコン 1 個に対応する**概念の配列**にほぐす。「ナビに home / search / settings / 通知 / ログアウト」なら 5 概念。「空状態のイラスト 1 枚」なら 1 概念。

各概念を英語の一般名詞 1 語に変換する。直訳が滑る語・カタカナ語の罠・抽象語の比喩化は `references/query-dictionary-ja.md` を読む。**変換に迷った語が 1 つでもあれば必ず読む**（吹き出し / 稟議 / コンセント / 成長 のような語は直訳すると別物に着地する）。

### 2. 棚を当てる

概念に対応するカテゴリを `references/categories-ja.md` の逆引き表から引く。特に次は翻訳検索では辿り着けないので、表を見ずに全体検索へ流さない。

- 空状態・完了画面 → `scene/uistate`
- マスコット・キャラ → `object/mascot` / `people/character`
- 感情・表情 → `people/emotion` / `face`
- 抽象概念 → `object/concept`

### 3. 候補を集める

- **2 概念以上**: `find_icons_for` に概念を配列で渡す（最大 20、`per_concept` は 3 前後）。概念ごとに `search_icons` を叩き直さない。
- **1 概念を深掘り**: `search_icons`。多語クエリで `NOT every word is reflected` の警告が出たら、一番重要な 1 語で引き直す。
- **棚を眺める**: `list_icons` に category を渡す。既定の `order: "generality"` でその棚の代表格が出る。発想を広げたいときだけ `order: "random"`。
- 0 件のときは日本語が混じっていないか、多語 AND で落ちていないかをまず疑う。次に上位語へ上げる（`sticky note` → `note` → `paper`）。

**画風を揃える**: 手描きなので混在が目立つ。セットで使うアイコンは同じ category、できれば同じ命名パターン（`confirmation-for-*` など）から選ぶ。

### 4. コンタクトシートで見せる（必須）

**slug の一覧だけを提示して採用を決めない。** 手描きアイコンは名前から絵が想像できず、slug だけ見せても選べない。必ず実物を並べて見せる。

```bash
scripts/contact_sheet.py --out <出力先.html> --title "<見出し>" \
  slug1:概念ラベル slug2:概念ラベル slug3
```

- `slug:ラベル` のラベルは、その候補がどの概念に対する提案かを日本語で書く。省略可。
- 出力は自己完結 HTML（SVG インライン、ライト / ダーク切替、実寸比保持、番号付き）。取得失敗した slug はカードにエラー表示され、他の候補は残る。
- 標準ライブラリのみで動く。依存パッケージなし。

シートの見せ方は環境に合わせる:

- **Artifact 機能がある環境**: `--fragment` を付けて生成し、その HTML を publish して URL を渡す。Artifact は doctype / html / head / body を自前で付けるため、このフラグなしのファイルを publish するとタグが二重になる。同じファイルパスで再 publish すれば URL が更新されるので、候補を差し替えても URL は増えない。
- **それ以外**: フラグなしで生成し、`open <出力先.html>`（macOS）でローカルビューアに渡す。パスを書くだけで済ませない。

見せたうえで**番号で選んでもらう**。承認を得るまで配置しない。

### 5. 採用分を配置する

承認後に用途で分岐する。

- **コードに埋める**: `get_icon_svg` でマークアップを取得（最大 20 slug まとめて可）し、コンポーネント / インライン SVG として書き込む。`fill="currentColor"` を書き換えない。サイズは高さか幅の片側だけ指定し、もう片方は `auto`。
- **URL 参照で足りる**: `https://koboyo.com/icons/svg/<slug>.svg` を組み立てる。マークアップの取得は不要。
- **資料・素材として渡す**: SVG ファイルを `~/Downloads/` に保存する。ユーザー指定があればそれを優先。

**生成物をこのスキルのディレクトリ配下に置かない。** コンタクトシートの HTML も作業用の一時ディレクトリか `~/Downloads/` に出す。

## 前提と注意

- **サイズと色の扱いは MCP の応答が毎回教えてくる**（縦横比はまちまち、正方形は 4% 未満、単色 `currentColor`）。ここでは繰り返さない。応答の SIZING / COLOR 行に従う。
- **ライセンス**を確認する必要が出たら `get_library_info` を呼ぶ。商用・改変・帰属不要だが、ライブラリ自体の再配布とアイコン抽出機能の実装は不可。受託納品への埋め込み可否を聞かれたらこれを根拠にする。
- **抽象語の絵は勝手に確定しない**。比喩に置き換えたときは、なぜその絵かを一言添えて確認する。
