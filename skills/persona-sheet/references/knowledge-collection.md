# 事業の情報の集め方とナレッジの書式

ペルソナの質は、ナレッジの質で決まる。サイトに書いてあることだけでは「お客さまの実際」が足りないことが多いので、聞き取りで補う。

## 1. 集め方

### Web サイト

- トップページを取得し、メニューやリンクから次のページを探して取得する。合わせて 10 ページまで
  - サービス・料金 / 会社概要・プロフィール / 事例・お客さまの声 / よくある質問 / ブログやお知らせの最新数件
- 取得できないとき（この AI が Web を見られない、ページが表示されない）は、主要なページの文章をコピーして貼ってもらう
- SNS（Instagram・Facebook など）はログインが要り、取得できないことが多い。プロフィール文と、反応のよかった投稿の要点を貼ってもらう
- Google マップの口コミがあれば、要点を貼ってもらう（お客さまの言葉がそのまま手に入る）

### 手元の資料

- `資料/` のファイルを読む。PDF・Word・Excel・テキスト・画像（チラシや店頭 POP の写真など）
- 読めない形式は、PDF にするか文章を貼ってもらう
- アンケート・お客さまの声・問い合わせメールは、個人を特定できる情報を除き、要点とお客さまの言い回しだけを書き写す

### 聞き取り

- 下の質問を 3 問ずつ聞く。答えにくい質問は飛ばしてよいと伝える
- 答えに具体的な出来事が出てきたら、1 つだけ深掘りする（「そのとき、お客さまは何と言っていましたか」「その前は、どうしていたそうですか」）
- お客さまの言葉は、言い換えずにそのまま書き留める。シートの「いちばんの願い」や「困っている場面」の材料になる

聞き取りの質問:

1. 事業をひとことで言うと、誰に、何を、どうやって届けていますか
2. 始めたきっかけと、大事にしている思いを教えてください
3. サービス（商品）と価格、届け方（対面・オンライン・期間）を教えてください
4. 活動している地域と、お客さまとの出会い方（紹介・SNS・検索・チラシなど）を教えてください
5. 今のお客さまはどんな人ですか（業種・年代・立場）。特に「この人のためにやっている」と思えるお客さまは、どんな人ですか
6. お客さまが最初に相談してくる困りごとを、お客さまの言葉のまま教えてください
7. お客さまが申し込む前に迷うこと・心配することは何ですか
8. 申し込みの決め手になったと言われたことはありますか
9. お客さまは、あなたに頼む前は何で済ませていましたか（他の会社、自分でやる、家族に頼む、あきらめる）
10. 申し込んだ後、お客さまに言われてうれしかったことは何ですか
11. 合わなかったお客さま、断ったお客さまはどんな人でしたか
12. これから増やしたいお客さまと、使える時間・人手（月に何時間、一人で など）を教えてください

## 2. ナレッジの書式

`ナレッジ/` に次の 5 つのファイルを作る。項目が分からないときは空欄にせず「未確認」と書く。各項目の末尾に出典を `（出典: サイト）` `（出典: 資料名）` `（出典: 聞き取り 2026-11-01）` のように添える。

### 事業の概要.md

```markdown
# 事業の概要

- 事業名・屋号:
- ひとことで言うと: 〈誰に〉〈何を〉〈どうやって〉
- 大事にしている思い:
- 強み・使える資源（経験、資格、設備、人脈）:
- 活動地域:
- 届け方（対面・オンライン・訪問・店舗）:
- 体制と使える時間（一人か、月に何時間か）:
- 更新日:
```

### サービス一覧.md

ペルソナを作るときの「対象サービス」の選択肢になる。サービスごとに見出しを分ける。

```markdown
# サービス一覧

## 〈サービス名〉
- 内容:
- 価格:
- 誰向けか:
- 形式・期間:
- 申し込みの入口（フォーム・電話・LINE・店頭）:
- 位置づけ: 入口 / 主力 / 継続 / その他
```

### お客さまの情報.md

```markdown
# お客さまの情報

## 今のお客さまの傾向
- 業種・立場・年代:
- 地域:
- 出会い方:

## お客さまの言葉（言い換えずに）
- 最初の相談でよく聞く困りごと:
- 申し込む前の迷い・心配:
- 決め手になったこと:
- 申し込んだ後に言われてうれしかったこと:

## 合わなかったお客さま
-

## 聞き取り・アンケートの要約（匿名）
-
```

### 競合と代わりの手段.md

```markdown
# 競合と代わりの手段

## 同じ業種の競合
- 〈名前か種類〉: 特徴 / 価格の目安 / 自分との違い

## 別の手段（お客さまが自分のサービスの代わりに使っているもの）
- 自分でやる:
- 家族・知人に頼む:
- 無料の情報（動画・本・SNS）で済ませる:
- 別の業種のサービス:
- 何もしない・我慢する:
```

### 出典.md

```markdown
# 出典

| 日付 | 種類 | どこから | 取り込んだ内容 |
|---|---|---|---|
| 2026-11-01 | サイト | https://example.com/service | サービスと価格 |
| 2026-11-01 | 資料 | 資料/会社案内.pdf | 事業の概要 |
| 2026-11-01 | 聞き取り | 本人 | お客さまの言葉 |
```

## 3. 更新のルール

- 追記するときは日付を添える。古い情報は消さず、「（2026-11 時点で終了）」のように残す
- 矛盾する情報が見つかったら、どちらが新しいかを利用者に確かめる
- サイトと聞き取りで言っていることが違うときは、聞き取りを優先する（サイトは古いことが多い）
- ナレッジを更新したら、既存のペルソナで影響を受ける人がいないかを確かめ、あれば作り直しを提案する
