# お客さまを考えるための考え方

ペルソナを書くときの土台。利用者に説明するときは、ここの言葉をそのまま読み上げず、利用者の事業の例に置き換えて短く話す。専門用語は使わないか、使うなら一言で言い換える。

## 1. 「みんな」ではなく「一人」を描く

- 誰にでも向けたサービスは、誰にも選ばれにくい。相手が一人に決まると、その人に合う値段・届け方・言葉を選べるようになる
- 流れは 3 段階。市場をいくつかに切り分ける → その中から狙う相手を選ぶ → 選んだ相手の頭の中で、自分がどう覚えられたいかを決める（マーケティングでは STP と呼ぶ）
- ペルソナは、2 段階目で選んだ相手を、実在しそうな一人の人物として描いたもの。平均像ではなく、具体的な一人にする

## 2. 切り分ける 4 つの見方

| 見方 | 見るもの |
|---|---|
| 属性 | 年齢・性別・家族・職業・収入 |
| 場所 | 住まい・職場・ふだん動く範囲 |
| 気持ち | 価値観・こだわり・暮らし方 |
| 行動 | 使う頻度・買うきっかけ・求めるもの |

1 つだけでは輪郭がぼやける。重ねるほど、どんな人かがはっきりする。

## 3. 「いつ」「どんなとき」まで絞る

属性だけでは顔が浮かばない。困りごとが起きる状況とタイミングまで書くと、届け方と伝える言葉が決まる。

| 属性だけ | 状況とタイミングまで |
|---|---|
| 40 代の会社員 | 子どもの受験が決まり、平日の夜が急に足りなくなった父親 |
| 飲食店の店主 | 仕込みと営業の合間の 15 分で、予約の電話を折り返している店主 |
| 工務店の経営者 | 見積の依頼が重なる春だけ、毎晩遅くまで事務所に残る二代目 |

## 4. 狙う相手を選ぶ 3 つの条件

マーケティングでは、市場の大きさ・伸び・競合の強さ・届けやすさ・反応の良さ（6R と呼ばれる観点）や、自社の目標と資源に合うかで狙う相手を選ぶ。小さな事業では、次の 3 つに絞ると判断しやすい。

| 条件 | 確かめること |
|---|---|
| 届けられる | 自分の告知や紹介の輪の中にいるか。直接会える、知り合いを通じて話が伝わる、などの道があるか |
| 払ってくれる | その困りごとのために、今すでに何かを払っているか（お金・時間・手間）。払っていない困りごとは、話題にはなっても申し込みにつながりにくい |
| 自分に合う | 自分の目指すこと・得意なこと・無理なく続けられる働き方と重なるか |

シートの分析メモで、それぞれに ◎ ○ △ × と理由を付ける。3 つとも ○ 以上の人から狙うのが基本。

## 5. 困りごとは 3 つの「不」で見る

日本のマーケティングや商品企画でよく使われる、困りごとの 3 分類。

| 不 | 中身 | サービスが応える方向の例 |
|---|---|---|
| 不便 | 面倒、時間を取られる、手が回らない | 手間を引き受ける、早く済むようにする |
| 不安 | よく分からない、失敗がこわい、人に聞けない | 分かる言葉で説明する、そばで支える、結果を約束する |
| 不満 | 今のものでは足りない、自分に合っていない | 中身を良くする、その人に合わせる |

3 つは別々の困りごとにする。同じ話の言い換えにしない。

## 6. その先のうれしさをたどる

要望をそのまま受け取らず、「それが大事なのはなぜか」「その先にどうなるとよいか」をたどる（インタビューでラダリングと呼ばれる聞き方）。2〜3 段たどった先が、その人が本当に片づけたい用事になる。

例: 「ホームページを新しくしたい」→ 問い合わせが増える → 紹介に頼らず、受ける仕事を自分で選べるようになる

シートには、表面の要望（ホームページ）ではなく、奥の用事（仕事を選べる）を書く。困りごとの裏返しだけでなく、その人が得たいもの（時間が増える、ほめられる、安心して眠れる）も意識する。

## 7. 人は用事を片づけるために商品を「雇う」

クレイトン・クリステンセンの「ジョブ理論」（『ジョブ理論』ハーパーコリンズ・ジャパン, 2017）の考え方。人は商品そのものが欲しいのではなく、片づけたい用事のために商品を雇う。

- 競合は同業だけではない。同じ用事を片づけられるものは、すべて競合になる。自分でやる、家族に頼む、無料の動画や本で済ませる、別の業種のサービスを使う、あきらめる
- だからシートに「いま使っている代わりの手段」を書く。「何もしない」「我慢する」も立派な答え
- 代わりの手段を知ると、自分の値段と伝え方の比べる相手が見える

## 8. 動き出す力と、止める力

ボブ・モエスタらが整理した、人が今のやり方から乗り換えるときに働く 4 つの力（Four Forces of Progress）。

| 力 | 向き | シートの欄 |
|---|---|---|
| 今への不満 | 動き出す | 3 つの「不」 |
| 新しいものへの期待 | 動き出す | 解消すると・本当に片づけたい用事 |
| 新しいものへの心配 | 止める | 買う前のためらい |
| 今のやり方への慣れ | 止める | いま使っている代わりの手段 |

- 動き出す力が止める力を上回ったときに、人は申し込む。困りごとが大きくても、ためらいと慣れが強ければ動かない
- 困りごとはずっと前からあっても、申し込むのは「きっかけの出来事」が起きたとき（子どもの入学、繁忙期の失敗、スタッフの退職、家族の入院など）。シートの「買うきっかけ」にはこの出来事を書く
- 「ためらい」をなくす手は、提供の仕方の工夫になる（お試し、少額の入口、実例を見せる、家族も一緒に聞ける）

## 9. どこで知り、どう調べて、何で申し込むか

お客さまがサービスに出会い、申し込み、人に話すまでの道すじ（カスタマージャーニー）。電通が提唱した AISAS（気づく → 興味を持つ → 調べる → 買う → 共有する）を、小さな事業向けに言い換えると次のようになる。シートの「知る・調べる場所」には、最初の 2 段階で使う場所を書く。

| 段階 | 場所や手段の例 |
|---|---|
| 気づく | 知人のすすめ、店の前、チラシ、SNS の投稿、Google マップ |
| 調べる | ホームページ、口コミの評価、Instagram の過去の投稿、知り合いに聞く |
| 申し込む | LINE、電話、予約フォーム、店頭 |
| 使う | 来店、訪問、オンライン、配送 |
| 人に話す | 口コミの投稿、家族や同業への紹介、SNS での紹介 |

- 満足したお客さまの「人に話す」が、次のお客さまの「気づく」「調べる」になる。地域の小さな事業ほど、この循環の効き目が大きい
- 信頼している人からの一言は、広告を何度も見るより強く背中を押す。ペルソナごとに「誰の話なら信じるか」を考え、「知る・調べる場所」に書く

## 10. 狙わない人も決める

- 「この人には売らない」と決めた人物像（ネガティブペルソナ）。値引き前提の人、自分の提供の形では応えられない人、理念が合わない人など
- 狙わない人を決めると、伝える言葉がぶれず、合わない依頼で時間を失うことが減る
- ペルソナの一覧に 1〜3 人を、理由と一緒に書く

## 11. お客さまが会社のとき

取引先が会社なら、買うかどうかを決める人、実際に使う人、意見を言う人が別々のことがある。ペルソナは主に「困りごとを感じている人」で描き、決める人が別にいるなら、その人の心配（費用の説明ができるか、社内が反対しないか）を「買う前のためらい」に書く。

## 12. ペルソナは仮説 ─ 確かめて育てる

- ペルソナには根拠の強さに段階がある。社内の思い込みだけで作ったもの、少人数のお客さまの話から作ったもの、大規模な調査から作ったもの（Nielsen Norman Group「Personas: 3 Types」）。AI が作るペルソナは、最初の段階の「想像（仮説）」にあたる
- AI が作る人物像は、性別や年代について型にはまった描写に寄りやすいことが研究で示されている（Cheng, Durmus, Jurafsky「Marked Personas」ACL 2023）。もっともらしく見えても、実在のお客さまで確かめるまでは仮説として扱う
- 西口一希さんの N1 分析（『たった一人の分析から事業は成長する』翔泳社, 2019）が示すように、実在する一人のお客さまを深く知ることが、いちばん確かな出発点になる。ナレッジに具体的なお客さまの話があれば、それを核にする（個人が特定されないように置き換える）
- 確かめ方: そのペルソナに近いお客さま 2〜3 人に、次の 4 つを聞く。答えが違ったら、ペルソナを直して根拠を「実在の人に確認済み」に上げる
  1. 最初に「なんとかしたい」と思ったのは、いつ、何があったときか
  2. それまでは、どうやって済ませていたか
  3. 申し込む前に、迷ったことや心配だったことは何か
  4. 最後の決め手は何だったか

## 13. ペルソナを伝える言葉につなぐ

- 伝える言葉は、サービスの中身（何をするか）ではなく、相手の何が変わるか（変わった後の姿）で書く。シートの「響く一言」はその見出し
- 相手がどこまで気づいているかで、効く言葉が変わる（エドワード・シュワルツの考え方を 3 段階に縮めたもの）
  - 困りごとに気づいていない人には、困っている場面を描いて「それ、困っていませんか」と気づいてもらう
  - 困りごとに気づき、解決の方法を探している人には、解決した後の姿を見せる
  - 方法を比べている人には、他との違いと、ためらいへの答え（お試し、実例、保証）を見せる
