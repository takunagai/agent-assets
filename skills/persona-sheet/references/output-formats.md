# 出力の手順

選ばれた形式をすべて作る。どの形式も、全員分を 1 つのファイルにまとめる。

- 保存先: `ペルソナづくり/シート/`
- ファイル名: `ペルソナシート_YYYY-MM-DD.<拡張子>`。同じ名前があれば `_2` `_3` を付ける（上書きしない）
- 並び順: ペルソナの番号順。人数が多いときは、今回作った人だけか、全員かを確かめる

## 1. データ（JSON）を先に作る

HTML・PDF・アーティファクト・JSON・YAML はどれも同じデータから作る。まず `ペルソナ/` の Markdown を読み、次の形のデータにする。

```json
{
  "business": "事業名",
  "service": "対象サービス（複数なら「、」でつなぐ。事業全体なら「事業全体」）",
  "created": "2026-11-01",
  "not_target": [
    { "who": "狙わない人", "reason": "理由" }
  ],
  "personas": [
    {
      "id": "01",
      "name": "佐藤 美穂",
      "age": 38,
      "role": "仕事・立場",
      "quote": "いちばんの願い（かぎかっこは付けない）",
      "tags": ["タグ", "タグ", "タグ"],
      "service": "対象サービス",
      "core": "困りごとの核",
      "basis": "想像（仮説）",
      "photo": "",
      "created": "2026-11-01",
      "profile": { "family": "家族", "area": "住まい・行動範囲", "scale": "暮らし・仕事の規模" },
      "day": [
        { "slot": "朝", "time": "6:00〜8:00", "text": "内容", "pain": true },
        { "slot": "昼", "time": "9:00〜17:30", "text": "内容", "pain": false },
        { "slot": "夕方", "time": "18:00〜20:00", "text": "内容", "pain": false },
        { "slot": "夜", "time": "21:00〜23:00", "text": "内容", "pain": false }
      ],
      "scene": { "when": "いつ", "where": "どこで", "what": "何が" },
      "alternatives": ["代わりの手段", "代わりの手段", "代わりの手段"],
      "fu": [
        { "kind": "不便", "text": "困りごと", "joy": "解消すると" },
        { "kind": "不安", "text": "困りごと", "joy": "解消すると" },
        { "kind": "不満", "text": "困りごと", "joy": "解消すると" }
      ],
      "job": "本当に片づけたい用事",
      "fit": {
        "reach": { "mark": "○", "note": "届けられる の理由" },
        "pay": { "mark": "○", "note": "払ってくれる の理由" },
        "match": { "mark": "◎", "note": "自分に合う の理由" }
      },
      "trigger": "買うきっかけ",
      "hesitation": "買う前のためらい",
      "channels": "知る・調べる場所",
      "entry": "最初にすすめる商品",
      "message": "響く一言（かぎかっこは付けない）"
    }
  ]
}
```

- 対応: Markdown の項目名 → キー。仕事・立場 → `role`、いちばんの願い → `quote`、【困りごと】の印 → `pain: true`、届けられる → `fit.reach`、払ってくれる → `fit.pay`、自分に合う → `fit.match`
- `not_target` は `ペルソナ/一覧.md` の「狙わない人」から取る
- 文字列の中の `"` は `\"` にする。改行は入れない
- コマンドを実行できるなら、JSON として読み込めるかを確かめる（例: `python3 -c "import json,sys; json.load(open(sys.argv[1], encoding='utf-8'))" <ファイル>`）
- コマンドを実行できるなら、この JSON から YAML・Markdown・HTML への変換を小さなスクリプトで行ってよい（一時フォルダに置く）。実行できない AI は、この節と各節の形に沿って手で書く

## 2. Markdown

1 つの `.md` にまとめる。

1. 表題 `# ペルソナシート ─ 〈事業名〉`、その下に対象サービス・人数・作成日
2. `## 顔ぶれ` に一覧表（`ペルソナ/一覧.md` と同じ列）と「狙わない人」
3. `## このペルソナを確かめる` に、`references/customer-thinking.md` 12 節の 4 つの質問
4. 各ペルソナのファイルの中身を番号順に `---` で区切ってつなげる（見出しは 1 段下げて `##` から始める）
5. 最後に 1 行: `架空の人物です。ペルソナシート作成スキル ─ AIワークラボ by ナガイ商店.com`

## 3. JSON

1 節のデータを `ペルソナシート_YYYY-MM-DD.json` に保存する（UTF-8、字下げ 2）。ほかのツールや表計算に取り込むためのもの。

## 4. YAML

1 節と同じ構造を YAML で `ペルソナシート_YYYY-MM-DD.yaml` に保存する。

- 文字列はすべてダブルクォートで囲む（`:` や `#` を含む日本語でも壊れないように）
- 字下げは半角スペース 2 つ。タブは使わない
- 数字の年齢だけクォートしない。`pain` は `true` / `false`

```yaml
business: "事業名"
created: "2026-11-01"
personas:
  - id: "01"
    name: "佐藤 美穂"
    age: 38
    tags: ["子育て世帯", "共働き", "転入 3 年目"]
    day:
      - { slot: "朝", time: "6:00〜8:00", text: "内容", pain: true }
```

## 5. HTML ページ

1. `assets/persona-sheet.html` を `シート/ペルソナシート_YYYY-MM-DD.html` にコピーする
2. `<script id="persona-data" type="application/json">` と `</script>` の間を、1 節のデータに置き換える。それ以外は変えない（デザインと動きが壊れる）
   - 埋め込む前に、JSON の文字列中の `<` `>` `&` を `<` `>` `&` に置き換える（`</script>` で埋め込みブロックが途切れ、集めた資料の文章がスクリプトとして動くのを防ぐ）。JSON としての意味は変わらず、`JSON.parse` はそのまま読める
3. 構成: 1 枚目が一覧ページ（12 人ごとに 1 枚）、その後に 1 人 1 枚
4. 開いて確かめられる AI なら、ブラウザで開いて確かめる
   - 一覧と全員分が出ているか
   - 紫の枠が付いたシートがないか（1 ページに収まらず、文字を最小まで小さくしても足りないしるし）。あれば、その人の文章を文字数の目安まで短くして作り直す
   - コマンドで確かめる場合: Chrome か Edge の `--headless --dump-dom` で開き、`<body data-overflow="0">` なら全員が収まっている
5. 開き方を伝える: 「`シート/` の HTML ファイルをダブルクリックすると、ブラウザで開きます」

## 6. PDF

まず 5 節の HTML を作る。PDF は HTML をブラウザで印刷して作る。

### コマンドを実行できるとき（自動）

Chrome か Edge があれば、そのまま PDF にできる。`<HTML>` と `<PDF>` は絶対パスにする。

- Mac（Chrome）

  ```bash
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="<PDF>" "<HTML>"
  ```

  Chrome がなく Edge があれば `/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge` に置き換える

- Windows（Edge。PowerShell）

  ```powershell
  & "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="<PDF>" "<HTML>"
  ```

  見つからなければ `C:\Program Files\Microsoft\Edge\Application\msedge.exe` を試す

- 実行中に `CVDisplayLinkCreateWithCGDisplay failed` や `task_policy_set` などのエラー行が出ても、PDF ができていれば問題ない
- 成功したら、ページ数が「一覧ページの枚数＋人数」になっているかを確かめる（例: `python3 -c "import re,sys; print(len(re.findall(rb'/Type\s*/Page[^s]', open(sys.argv[1],'rb').read())))" <PDF>`）
- AI の安全のための制限（サンドボックス）の中では、ブラウザがすぐ終了して PDF ができないことがある。1 回失敗したら繰り返さず、下の「手で保存」の手順を伝える
- 写真を付けた場合、PDF が数十 MB になることがある。重いときは 7 節の手順で写真を縮めてから作り直す

### コマンドを実行できない・ブラウザが見つからないとき（手で保存）

利用者に次の手順を伝える。

1. `シート/` の HTML ファイルをダブルクリックして開く（Chrome か Edge がおすすめ。Safari でもできる）
2. 画面の上の「印刷・PDF 保存」ボタンを押す（キーボードなら Windows は Ctrl＋P、Mac は ⌘＋P）
3. 送信先（プリンター）を「PDF に保存」にする
4. 「詳細設定」で、用紙サイズ A4、余白「なし」、「背景のグラフィック」をオン、「ヘッダーとフッター」をオフにする
5. 「保存」を押す

## 7. 写真（画像を生成できる AI のときだけ）

AI 自身に画像生成がなくても、画像生成のスキルや MCP（GPT Image 2・Nano Banana など）が使えるなら、それで作ってよい。使い方はそのスキルや MCP の説明に従う。

- 1 人 1 枚、正方形。保存先は `シート/写真/NN_氏名.<拡張子>`。拡張子は生成された形式のまま（png・jpg・webp のどれでも表示できる）。データの `photo` には、保存した名前どおりに `写真/NN_氏名.jpg` のように書く（HTML から見た相対パス）。Markdown・YAML・JSON の写真の欄も同じ名前にそろえる
- 顔ぶれの違いが写真でも分かるように描き分ける（髪型、眼鏡、体格、服装、背景の場所）。同じ年代・性別の人が並ぶときは特に気をつける
- プロンプトのひな形（〈 〉を埋める）:

  > 日本に住む〈年齢〉歳の〈性別〉。〈仕事・立場〉。〈髪型・眼鏡などの見た目の特徴〉。〈服装〉。〈ふだんいる場所〉を背景に、自然光で上半身を撮った、やわらかく落ち着いた雰囲気の写真。穏やかな表情で、カメラの少し横を見ている。正方形。文字やロゴは入れない。実在の人物に似せない。

- 生成に失敗した人は、`photo` を空にする（頭文字のアイコンになる）。失敗を何度も繰り返さない
- 縮められるなら、長い辺 800 ピクセルの JPEG にする（PDF が軽くなる）。Mac では `sips -Z 800 -s format jpeg 〈元.png〉 --out 〈写真/NN_氏名.jpg〉`。縮めたら `photo` の拡張子も直す
- 写真のあるシートには、下の欄に「写真は AI で生成しています」と自動で入る

## 8. アーティファクト（表示できる AI のときだけ）

- 5 節で作った HTML の全文を、そのままアーティファクトとして表示する
- アーティファクトからは手元の写真ファイルを読めないため、`photo` を空にしたデータで作る（頭文字のアイコンになる）
- アーティファクトの中では印刷ボタンが効かないことがある。PDF が要るときは、HTML ファイルの方を使うよう伝える
- 表示できない AI では、HTML ページに切り替えて、その旨を伝える

## 9. クレジット

シートと一覧ページの下に「ペルソナシート作成スキル ─ AIワークラボ by ナガイ商店.com」が入る。利用者に消したいと言われたら、コピーした HTML の中の `var CREDIT = "…";` を `var CREDIT = "";` にする。Markdown では最後の 1 行から外す。
